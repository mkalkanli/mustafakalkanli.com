# Mustafa Kalkanlı Personal Cybersecurity Site Design

## Goal

Publish a fast, indexable, bilingual personal site that builds Mustafa Kalkanlı's reputation in cybersecurity management and strategy, supported by digital forensics expertise.

## Experience

The first release is a single-page editorial profile. Turkish is the default language and a prominent control switches every visible section to English. The page leads with a concise positioning statement, explains the strategic and forensic focus areas, presents an approach built around governance, resilience, and evidence, and links only to the user-confirmed GitHub profile.

## Visual direction

Use a restrained executive aesthetic: warm off-white background, near-black typography, deep navy panels, and a controlled electric-blue accent. Avoid generic hacker imagery, neon-green code, fake dashboards, fabricated statistics, and unverifiable credentials. Typography, spacing, and subtle grid geometry carry the design.

## Indexing and trust

The rendered HTML must contain meaningful Turkish content without requiring interaction. Provide a canonical URL, description, Open Graph metadata, Person JSON-LD containing only verified claims, robots.txt, and sitemap.xml. English copy is available interactively in this first release; dedicated locale routes can follow when deeper content is available.

## Scope

- One responsive page
- Turkish and English copy
- Cybersecurity management and strategy as the primary expertise
- Digital forensics as a supporting specialty
- Confirmed GitHub link only
- No contact form, biography claims, client logos, certifications, testimonials, or portrait until verified

## Verification

Automated tests check bilingual content completeness, SEO constraints, confirmed links, and required metadata. The production build must complete successfully before publishing.
